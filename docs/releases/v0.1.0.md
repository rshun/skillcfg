# Skill Hub v0.1.0（桌面安装包与 CLI 候选说明）

交付第一至第四阶段（Tasks 1–12）完整功能。每次预览后手动应用，无后台自动同步。

- 内置 Codex、Claude Code、Antigravity、Grok Build 档案；普通新增 Agent 通过 JSON 配置接入。
- 完整 Skill 包导入、库管理与不可变 revision，保留资源、原文字节、CRLF、二进制及 Unix 执行位。
- 精确 Skill/Agent 配对、差异预览、共享目录可见性重算、手动应用、完整备份与显式恢复。
- 桌面端雾蓝工作台（四页、五个任务弹窗、明暗主题、窄视口及 200% 缩放适配）与 Tauri 原生桥接。
- 同一已构建可执行文件（桌面与 CLI）支持运行时添加第五个 Agent JSON，完成导入、分发、探针切换及恢复，无需重新编译。
- 恢复前校验内容与物理身份；处理真实进程退出、活跃锁、跨卷备份及首次导入中断，不执行删除文件操作。

## 平台产物清单（`skill-hub-release-bundles`）

- **Windows x64**：`skill-hub-desktop-v0.1.0-windows-x64-setup.exe`（NSIS）、`.msi`、`-portable.zip`，以及 `skill-hub-cli-v0.1.0-windows-x64.zip`（Windows 10 1803+ / Windows 11 x64，需 Edge WebView2 Runtime；当前未配置 Authenticode 代码签名）。
- **macOS Apple Silicon（arm64）与 Intel（x64）**：分架构独立原生构建，各提供 `.dmg`、`.app.tar.gz` 与 CLI `.tar.gz`（macOS 11+，系统 `WKWebView`；当前未配置 Apple Developer 签名与公证）。
- **Linux x64**：`skill-hub-desktop-v0.1.0-linux-x64.AppImage`、`.deb` 与 CLI `.tar.gz`（基于 Ubuntu 24.04 构建，仅声明兼容 `glibc >= 2.39` 且具备 `libwebkit2gtk-4.1-0` / `libgtk-3-0` 的 x86_64 图形桌面环境）。

`SHA256SUMS.txt` 与 `BUILD-BASELINE.md` 提供全部 13 个产物的 SHA-256 摘要与构建环境基线。首次使用请按 [人工验收手册](../MANUAL-VALIDATION.md) 先以 `--home <隔离绝对目录>` 完成宿主机验证，再对本机真实 Agent 逐个核对实际发现与加载（`A14`）；未获单独授权前不自动打标签或发布正式 GitHub Release。
