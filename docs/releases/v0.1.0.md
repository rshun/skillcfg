# Skill Hub v0.1.0 CLI

首个 CLI 版本，交付第一、第二阶段功能。每次预览后手动应用，无自动同步。

- 内置 Codex、Claude Code、Antigravity、Grok Build 档案；普通新增 Agent 通过 JSON 配置接入。
- 完整 Skill 包导入、库管理与不可变 revision，保留资源、原文字节及执行位。
- 精确 Skill/Agent 配对、差异预览、手动应用、完整备份与显式恢复。
- 同一可执行文件支持添加第五个 Agent，完成导入、分发及恢复，无需重新编译。
- 恢复前校验内容与物理身份；处理真实进程退出、活跃锁、跨卷备份及首次导入中断。

下载对应平台 ZIP，解压后运行 `skill-hub --help`，Windows 使用 `skill-hub.exe`。首次建议用 `--home` 指向临时目录验证工作流。包内包含 CLI 与恢复说明；`SHA256SUMS.txt` 提供四个 ZIP 的 SHA-256。

提供 Linux x64、Windows x64、macOS ARM64 和 macOS x64。所有依赖、测试、Clippy、格式检查、编译、打包和包内字节校验在 GitHub Actions 执行。

当前为 CLI 发布。桌面界面、安装包和真实 Agent 加载的最终人工验收属于后续阶段；CLI 成功写入不等于 Agent 已实际加载。macOS 二进制尚未签名或公证。使用方式及写入/恢复边界见包内 CLI.md、SAFETY.md。
