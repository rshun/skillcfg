# Skill Hub v0.3.0（对齐 MCP Hub 桌面工作台视觉与批量矩阵）

在 `v0.2.0` 三平台桌面端与事务安全引擎基础上，将桌面端前端视觉体系与工作台交互全面对齐姊妹项目 **MCP Hub（`mcpconfig`）**，同时保持零新增第三方依赖、零自动同步、每次写入前强制预览确认。

## 核心更新

- **MCP Hub 统一视觉体系与 6 套强调色**：默认采用 `ocean`（晴空蓝）主题，内置 `ocean` / `violet` / `amber` / `emerald` / `rose` / `slate` 6 套强调色与浅色 / 深色模式本地持久化切换；顶栏集成调色盘快切弹层、明暗切换与刷新动作。
- **工作台双栏布局与配置库快切**：左侧 `224px` 导航栏（`<=760px` 视口自动收窄为图标轨）底部新增「当前配置库」卡片与快切弹窗（乐观锁 `revision` 校验 + 原生目录选择）；中心库采用「左表 + 右侧 `360px` 可折叠详情栏 + 底部已选操作条」结构，桌面默认窗口尺寸升级为 `1320×860`。
- **15 款智能体矢量品牌徽标（`AgentBadge`）**：内置 Claude Code、Claude Desktop、Codex、OpenCode、Antigravity、Grok、Cursor、Windsurf、VS Code、Cline、Gemini CLI、Kimi Code、Trae、WorkBuddy、OpenClaw 等矢量品牌徽标，自动剥离 `custom.` 前缀并提供通用终端回退图标。
- **`Skill × Agent` 全屏批量选择矩阵**：新增矩阵选择弹窗，支持按列整列全选/取消、实时统计待分发配对并一键进入同步预览门禁。
- **完整保留安全事务门禁与可访问性**：全选二次确认、缺失中心源阻断、路径/安全阻断项拦截、逐文件 Diff 必读勾选确认、无删备份恢复、零重编译接入第五个 Agent，以及 `320–1024px` 响应式与 `200%` 缩放无水平溢出全部通过真实 Chrome 端到端回归（27 个测试子场景）。
- **云端打包稳定性加固**：`release.yml` 新增通过 GitHub API 预热并校验 Tauri 打包工具缓存（`NSIS` / `WiX` / `AppRun` / `linuxdeploy`）及重试保护，消除网页重定向节点偶发 `HTTP 504` 导致的构建波动。

## 最低系统基线与重要边界说明

- **Windows x64**：Windows 10（1803+）或 Windows 11 x64，需 Microsoft Edge WebView2 Runtime；当前未配置 Authenticode 签名，首次运行可能出现 SmartScreen 提示。
- **macOS arm64 / x64**：macOS 11+，使用系统 `WKWebView`；当前未配置 Apple Developer 签名与公证（Notarization），下载后需在“系统设置 -> 隐私与安全性”手动允许。
- **Linux x64**：基于 Ubuntu 24.04 构建，**仅声明兼容 `glibc >= 2.39`** 且安装有 `libwebkit2gtk-4.1-0`、`libgtk-3-0`、`libayatana-appindicator3-1`、`librsvg2-2` 的 x86_64 图形会话（无 FUSE 环境可为 AppImage 传 `--appimage-extract-and-run`）。
- **人工验收边界（`A14`）**：GitHub Actions 自动化构建与测试全绿**不等于**系统原生目录对话框已完成人工点击，**也不等于**本机真实外部 Agent 已实际发现或加载 Skill。首次使用请按包内 `MANUAL-VALIDATION.md` 先以 `--home <隔离绝对目录>` 验证，再逐个核对真实 Agent 加载结果。
