# Skill Hub v0.2.0（桌面工作台、三平台安装包与 CLI）

交付第一至第四阶段（Tasks 1–12）完整能力，在 `v0.1.0` CLI 基础上新增 **三平台桌面工作台（Tauri v2 原生桥接）** 与 **四架构桌面安装包/免安装归档**。坚持每次预览后手动应用，无后台守护或自动同步。

## 核心特性

- **桌面工作台与 Tauri 原生桥接**：四页导航（我的 Skills、Agents、变更历史、设置）与五个任务弹窗，支持明暗主题、320–1024px 响应式布局、键盘 `Escape` 焦点回收及 200% 缩放。
- **精确配对与共享可见性**：按 `package_id -> agent_id[]` 精确配对（不求笛卡尔积），基于实际规范化物理根与 JSON/TOML 布尔探针动态重算共享读取影响。
- **零重编译扩展第五个 Agent**：内置 Codex、Claude Code、Antigravity、Grok Build 档案；同一已构建桌面与 CLI 可执行文件仅需新增并授权运行时 `custom.<slug>.json` 档案即可完成导入、预览、应用、探针切换与恢复。
- **完整包保真与无删恢复**：保留原文字节、未知 frontmatter、UTF-8 中文、CRLF、二进制资源、空目录及 Unix 执行位；跨平台统一拦截 Windows 保留名（`CON`/`NUL` 等）、控制字符与大小写折叠冲突；每次写入先完整备份再切换，恢复时归档移出加载目录且不删除历史备份文件。

## 最低系统基线与重要边界说明

- **Windows x64**：Windows 10（1803+）或 Windows 11 x64，需 Microsoft Edge WebView2 Runtime；当前未配置 Authenticode 签名，首次运行可能出现 SmartScreen 提示。
- **macOS arm64 / x64**：macOS 11+，使用系统 `WKWebView`；当前未配置 Apple Developer 签名与公证（Notarization），下载后需在“系统设置 -> 隐私与安全性”手动允许。
- **Linux x64**：基于 Ubuntu 24.04 构建，**仅声明兼容 `glibc >= 2.39`** 且安装有 `libwebkit2gtk-4.1-0`、`libgtk-3-0`、`libayatana-appindicator3-1`、`librsvg2-2` 的 x86_64 图形会话（无 FUSE 环境可为 AppImage 传 `--appimage-extract-and-run`）。
- **人工验收边界（`A14`）**：GitHub Actions 自动化构建与测试全绿**不等于**系统原生目录对话框已完成人工点击，**也不等于**本机真实外部 Agent 已实际发现或加载 Skill。首次使用请按包内 `MANUAL-VALIDATION.md` 先以 `--home <隔离绝对目录>` 验证，再逐个核对真实 Agent 加载结果。
